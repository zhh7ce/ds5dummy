# DS5Dummy v0.1.3

配置页面并入主程序包、保存后自动生效；修复 SteamOS 上的接管失败与下行音频卡死。

## 新增

- 配置页面随主程序包安装，不再单独发布 `ds5dummy-config` 包。
- 保存配置后自动重启服务，约两秒生效，无需手动 `systemctl restart`。
- Deck 面板新增「配置页面」开关，可在局域网内其他电脑的浏览器上改配置。

## 变更

- Decky 插件改为自行编译后端与前端，按官方白名单打包。
- 插件目录改为整棵便携树，位于 `bin/ds5dummy/` 下。
- 路径布局改为编译期二选一（`fhs` / `tree`），dist 树自带 `etc/` 与 `VERSION`。
- 接管时等待 in-tree 驱动目录的时间由 5 秒缩短到 1 秒。
- 音频环容量重算：编码环 1.6 秒降到 341 毫秒，麦克风源环 2048 帧增到 3840 帧。
- 移除 boost 构建依赖。

## 修复

- 修复 SteamOS 上未加载 `libcomposite` 导致虚拟手柄建不起来。
- 修复覆盖安装后残留进程占用 UDC、新进程反复退避的问题。
- 修复下行音频偶发卡死、需重启音频流才能恢复的问题。
- 修复长时间静音后第一个有声帧被旧滤波状态插值的问题。
- 修复静音期间仍向 Opus 编码静音包、白耗重采样与编码的问题。
- 修复配置页面自动打开浏览器、把 Steam 客户端切走的问题。

## 升级

- Arch：直接安装新版 `ds5dummy-bin`，旧配置包由 pacman 自动替换；新增 `python`、`python-yaml` 依赖。
- Deck：覆盖安装插件 ZIP，`~/.config/ds5dummy/` 中的配置不受影响。
- 内核驱动无变化，`driver.v1` 无需重装。
